# booking

Booking Service на порту 8082. BCrypt, JWT, администрирование пользователей. BookingService координирует сагу; BookingTransactions фиксирует локальные шаги; HotelClient задаёт тайм-ауты и повторы.

Запуск и API описаны в [корневом README](../README.md). Сборка всего проекта из корня: ./mvnw.cmd verify.
