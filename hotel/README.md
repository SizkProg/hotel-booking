# hotel

Hotel Service на порту 8081. CRUD гостиниц и номеров, подбор по периоду, исторические счётчики и сериализованное резервирование. InventoryService содержит транзакционную бизнес-логику.

Запуск и API описаны в [корневом README](../README.md). Сборка всего проекта из корня: ./mvnw.cmd verify.
