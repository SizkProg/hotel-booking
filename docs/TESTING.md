# Проверка проекта

Из корня проекта:

```shell
./mvnw.cmd verify
```

На Linux и macOS: `sh mvnw verify`.

В проекте 22 теста:

| Класс | Что проверяет | Количество |
|---|---|---|
| GatewayTest | Запуск Gateway и запрет внутреннего маршрута | 1 |
| HotelSecurityTest | Аутентификация, роли, валидация, внутренний секрет | 5 |
| InventoryTest | Конкурентные брони, повтор запроса, отмена и интервалы дат | 5 |
| AuthTest | Регистрация, неверный пароль, запрос без авторизации | 3 |
| HotelClientTest | HTTP-повторы при 503, отсутствие повторов при 409 | 2 |
| SagaTest | Подтверждение, компенсация, тайм-аут, права владельца | 6 |

Тесты Hotel работают с H2. В тестах саги HotelClient заменён моком, а Booking использует H2. В HotelClientTest запросы отправляются на локальный HTTP-сервер.

Для проверки всей системы после сборки можно выполнить `node scripts/e2e.cjs`. Нужны Node.js 18+ и свободные порты 8080–8082 и 8761. Скрипт запускает четыре приложения, проверяет бронирование через Gateway и останавливает приложения. Результаты сохранены в [E2E-results.txt](E2E-results.txt).

Последняя проверка 7 ноября 2026 года: 22 теста без ошибок, сквозной сценарий завершён успешно. Docker Compose отдельно не проверялся.
