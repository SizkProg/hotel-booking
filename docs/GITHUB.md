# Публикация на GitHub

Локальный репозиторий настроен на автора:

```text
SizkProg <nikitamonich@gmail.com>
```

Перед публикацией проверьте, что этот email добавлен к нужному аккаунту GitHub. GitHub связывает коммиты с аккаунтом по email, а не по имени автора.

## Публикация из папки проекта

Создайте пустой репозиторий в своём аккаунте GitHub, без README, лицензии и .gitignore. В GitHub Desktop выберите File → Add local repository и укажите папку hotel-booking. После этого используйте Publish repository либо настройте адрес уже созданного репозитория.

Список авторов можно проверить командой:

```shell
git shortlog -sne HEAD
```

## Если проект распакован из ZIP

ZIP содержит исходники, без каталога .git. Чтобы создать новую историю с нужным автором, выполните из распакованной папки:

```shell
git init -b main
git config user.name "SizkProg"
git config user.email "nikitamonich@gmail.com"
git add .
git commit -m "Добавлен проект бронирования отелей"
```

Затем добавьте эту папку в GitHub Desktop и опубликуйте репозиторий. Не копируйте в проект историю .git из чужих репозиториев. Настройки автора применяются только к этому проекту.
